# MisarSEO agents

Task-scoped agents built on the @misarseo/mcp MCP server. Each bundles a subset
of the tools with the rules for using them safely.

| Agent | Purpose |
| --- | --- |
| `seo-strategist` | Researches keywords, gaps and competitors, then turns the findings into a prioritised content and ranking plan. |
| `site-auditor` | Runs and reads site audits — Core Web Vitals, internal links, structured data, HTTPS — and returns a ranked fix list. |
| `visibility-tracker` | Tracks rankings, Search Console performance and AI-search mentions, and reports what moved and why. |

All of them require authentication — see https://docs.misar.io/seo/mcp. Generated by
`scripts/mcp/generate-distribution.mjs`; edit the product entry, not these files.
